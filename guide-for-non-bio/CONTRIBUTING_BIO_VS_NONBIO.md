#  Contributing to Non-Bio Documentation

Thank you for contributing to OpenOncology! To ensure our codebase remains accessible to both computer scientists and domain bioscientists, we maintain a dedicated `non-bio-docs/` directory.

---

## 1. Documentation Principles

1. **Lead with CS Analogies:** Always pair biological terms with equivalent software engineering, system architecture, or data structure concepts.
2. **Avoid Unnecessary Jargon:** Define domain terms on first use.
3. **Use Standard Naming Conventions:** Keep all folder and file names in `kebab-case` without spaces (e.g., `non-bio-docs/`).
